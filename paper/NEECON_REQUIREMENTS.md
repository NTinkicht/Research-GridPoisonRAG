# NEECON 2026 submission requirements

Checked against the official NEECON website on 7 Oct 2026.

## Manuscript

- Standard IEEE two-column format.
- **4-6 pages**.
- Submission through EDAS with the related Track and Technical Session selected.
- Manuscript must contain a complete contribution description **and results**.
- Work must be framed against related state of the art.

Official author resources:
https://neecon.org/author-resources/

## AI-use disclosure

NEECON explicitly requires use of generative AI tools to be **disclosed in the manuscript**. Authors remain responsible for accuracy, originality and integrity; AI tools cannot be authors.

This repository therefore includes an AI-use disclosure in `paper/main.tex`. Do not remove it.

## Paper-scope implication

The 4-6 page limit means the manuscript should carry only:
1. threat model and novelty distinction;
2. GridPoison-100 construction;
3. the two-stage exposure/adoption design;
4. primary defense comparison;
5. compact results/limitations.

Detailed ablations, item tables and extended implementation notes belong in the repository, not the paper body.
